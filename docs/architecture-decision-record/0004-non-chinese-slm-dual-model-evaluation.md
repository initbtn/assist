# 0004. 비중국권 경량 SLM 듀얼 모델(Gemma 3 vs Hermes 3) 선정 및 A/B 병행 평가 체계

- **상태**: 승인됨 (Accepted)
- **날짜**: 2026-11-12

## 맥락 (Context)

`assist` 시스템은 엔터프라이즈 개발 동향 및 기술 아티클을 수집하여 로컬/온디맨드 GPU 기반의 소형 언어 모델(sLM)로 요약·합성하고 텔레그램 봇 및 웹으로 제공합니다.
인공지능 모델 채택 및 서빙 환경 구성 시 다음과 같은 기술적·보안적 요구사항이 존재합니다:

1. **데이터 주권 및 공급망 투명성**:
   - 기업 내부 지식 베이스, 프라이빗 소스코드 및 기술 분석 데이터가 외부 상용 API(OpenAI 등)로 유출되지 않도록 온프레미스/사설 환경에서 서빙 가능해야 합니다.
   - 라이선스 및 데이터 보안 신뢰성을 보장하기 위해 비중국권 빅테크 및 글로벌 오픈 커뮤니티가 공개한 투명한 오픈 가중치 모델을 엄격히 채택합니다.
2. **단일 모델 종속(Vendor Lock-in) 방지 및 품질 검증**:
   - 단일 모델에 의존할 경우 특정 모델의 프롬프트 편향, 환각(Hallucination), 한국어 기술 요약 품질 저하를 사전에 판별하기 어렵습니다.
   - 상이한 아키텍처와 미세조정 배경을 가진 두 개의 오픈 모델을 병행 운용하여 출력 품질과 추론 속도를 실시간 비교할 수 있는 A/B 평가 인프라가 필요합니다.

## 결정 (Decision)

### 1. 비중국권 모델 및 임베딩 선정 원칙
- **생성 모델 (SLM)**:
  - **모델 A: `gemma3:12b`** (Google DeepMind) — 고도의 추론 능력과 최신 아키텍처 지원.
  - **모델 C: `hermes3:8b`** (Nous Research / Meta Llama 3 기반 미세조정) — 오픈소스 정렬(Alignment) 및 지시 이행 능력 검증.
  - 중국계 모델(Qwen, DeepSeek 등)은 데이터 프라이버시 및 보안 공급망 원칙에 따라 프로젝트 범위에서 원천 배제합니다.
- **임베딩 모델**:
  - **`Snowflake/snowflake-arctic-embed-l-v2.0`** (미국 Snowflake) — 고성능 엔터프라이즈 벡터 검색 및 PGVector 연동.

### 2. A/B 병행 비교 엔드포인트 운용 (`POST /brief/compare`)
- 동일한 수집 컨텍스트에 대해 모델 A와 모델 C를 동시에 호출하여 한국어 3줄 요약 응답, 추론 소요 시간, 토큰 효율성을 비교 측정할 수 있는 엔드포인트를 표준 인터페이스로 유지합니다.
- 실측된 비교 결과(`docs/model-comparison-report.md`)를 바탕으로 주력(Primary) 모델을 확정하고, 특화 도메인(예: 아키텍처/FSD 코드 리뷰)별 최적 모델을 선별합니다.

### 3. 온디맨드 T4 GPU 수명주기 데몬과의 결합
- 상시 GPU 가동 비용을 방지하기 위해 Google Colab T4 GPU 기반의 자율 수명주기 엔진(`start_idle_watcher`)을 결합하여, 유휴 15분 경과 시 자동으로 Scale-to-Zero(`colab stop`)하고 RAG 질의 발생 시 JIT Auto-Wakeup으로 가동합니다.

## 근거 및 트레이드오프 (Consequences & Trade-offs)

### 이점
- **보안 및 규정 준수**: 투명한 비중국권 모델 라인업으로 기업 보안 감사 요건 충족.
- **평가 객관성**: 듀얼 모델 병행 평가를 통해 환각을 교차 검증하고 작업별 최적 모델을 데이터 기반으로 선택 가능.
- **비용 최적화**: 유료 상용 API 호출 비용 없이 무료/저비용 GPU 환경에서 고품질 요약 및 코드 리뷰 파이프라인 유지.

### 트레이드오프
- 듀얼 모델을 온디맨드 환경에 적재할 경우 모델 가중치 교체(Ollama Pull / Memory Swap) 오버헤드가 발생할 수 있으므로, 단일 세션에서는 주력 모델(`gemma3:12b`)을 기본 활성화하고 비교 검증 시에만 두 모델을 순차/병렬 스케줄링합니다.
