# Gemma 3 vs Hermes 3 모델 비교 검증 및 주력 모델 확정 보고서

## 1. 개요 및 검증 배경 (이슈 #19)
- **목적**: `Snowflake/snowflake-arctic-embed-l-v2.0` 임베딩 기반으로 수집된 기술 문서에 대해, 비중국권 오픈 가중치 모델인 **Gemma 3 12B (Model A)**와 **Hermes 3 8B (Model C)**의 한국어 3줄 요약 품질 및 실시간 추론 지연 시간을 비교 검증하고 최종 주력 모델을 확정함.
- **실행 환경**:
  - 런타임: Google Colab T4 GPU (Ollama 데몬 및 Cloudflare Tunnel 연동) 및 외부 컨테이너 환경
  - API 엔드포인트: `POST /brief/compare` (`{"models": ["A", "C"], "domain": "ai"}`)
  - 실측 로그: [`docs/benchmark-gemma3-vs-hermes3.json`](./benchmark-gemma3-vs-hermes3.json)

## 2. 모델별 비교 결과 요약

| 평가 항목 | Gemma 3 (12B, Model A) | Hermes 3 (8B, Model C) |
| :--- | :--- | :--- |
| **파라미터** | 12B | 8B |
| **추론 소요 시간** | ~3.4초 | ~2.6초 |
| **한국어 자연스러움** | **우수** (자연스러운 조사 결합 및 어미 처리) | **보통** (일부 영어 번역투 및 어색한 직역 존재) |
| **3줄 요약 지침 준수** | **우수** (3개의 명확한 핵심 개조식 문장 도출) | **양호** (문장이 다소 길어지고 서술형으로 분산됨) |
| **기술 용어 보존율** | **우수** (RAG 컨텍스트의 핵심 키워드 정확 추출) | **보통** (일반적인 표현으로 치환되는 경향) |

## 3. 최종 결정: 주력 모델 확정
- **확정 모델**: **`gemma3:12b` (Model A)**
- **선정 사유**:
  1. Hermes 3 대비 약 0.8초의 추가 지연이 있으나, 일일 배치 브리핑(3줄 요약) 목적상 3~4초대의 응답 시간은 비동기 파이프라인에서 완벽히 수용 가능함.
  2. 텔레그램 메신저로 전달되는 일일 브리핑 특성상 모바일 가독성과 자연스러운 한국어 문맥 품질이 핵심 가치이며, 이 영역에서 Gemma 3의 요약 완성도가 압도적으로 우수함.
  3. 향후 프로덕션 환경의 `DEFAULT_LLM_MODEL` 기본값으로 `gemma3:12b`를 표준 적용함.
